# Code of conduct

Treat contributors and users with respect. Discuss ideas and code without personal attacks. Harassment, discrimination, threats, sexualized conduct and sharing another person's private information are not acceptable.

This applies to issues, pull requests, discussions and other project spaces. Keep feedback specific and constructive.

The repository owner, [@maneeshv](https://github.com/maneeshv), may remove inappropriate content or restrict participation. For conduct concerns, use a contact method listed on the owner's public profile. If none is available, request a private contact without posting sensitive details. Do not use security advisories for unrelated conduct reports.
