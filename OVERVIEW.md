# Host handoff

Continue an agent's work on another Paseo host. Choose a host and destination project, review source files and curated chat, and create a fresh agent in a new isolated checkout. The original checkout and saved session are retained.

Fork Chat context is verified for stock Paseo 0.15.2 and 0.15.4 using the published official helper and public timeline, without a core patch. SSH restore, parity verification, recovery and return checks have disposable local tests. A destination still needs an explicitly approved SSH binding and independent readiness checks.

Open Host handoff from the Command Center, /handoff, or the composer Handoff control. Checks accept idle sources and validated saved closed Codex sources. Reading history can reopen normal session hooks and provider/MCP processes without sending a prompt. Running, permission-pending and errored sources are blocked. Online relay hosts are not automatically SSH-verified.

The plugin reads source Git state and registered destination projects. Checks list paths, sizes, hashes, exclusions and chat counts. Tracked relative links directly to tracked regular files are kept as links; unsafe links, submodules, conflicts, configured Git filters and suspected secrets block transfer. Raw timeline rows are transient; only curated context crosses hosts. Credential stores/environment are not copied, but pasted chat secrets may survive heuristic detection. Coordinator state stays in its private handoff directory; captures and restored files can also remain in approved private directories on the participating hosts.

Requires Git and macOS or Linux. Supported sources are exactly 0.15.2 and 0.15.4; destinations also include 0.15.0, which cannot be a return source. Live CLI identity and provider readiness are checked. Unknown versions block activation, not preview. An agent can queue after a successful turn; new prompts cancel and changed choices require review. Reloaded queues recover on the next ordinary plugin interaction. The plugin never stops or archives sources. Handoff does not enforce exclusive ownership: avoid new source work during transfer. Failed checks after restore can leave an isolated checkout for recovery. Return is a new continuation, never apply-back or merge.

Bring back in the global screen coordinates a return on this installation using its existing outbound SSH connection to the source. No reverse SSH or source-side plugin is required. A bundled capture helper is staged in the approved private source directory and runs on demand. Currently verified: source 0.15.4 to local coordinator/destination 0.15.2. Select a completed outbound continuation, check files/chat, then start into a new local folder. The original folder must remain unchanged. Archived sources require explicit unarchive. There is one return per outbound receipt; a completed return opens its existing agent. Durable recovery reuses the same operation; unknown agent creation is reconciled rather than repeated. SSH bindings require manual reviewed configuration; see the README for setup.

The fresh destination agent can send supplied chat, prompts and subsequent tool/file results to its configured model provider. SSH encryption and local storage do not imply that data stays only on your devices. Live acceptance used macOS and Codex; Linux is an implementation target, while native mobile and other provider/toolchain combinations remain unverified. This is a community plugin, not an official Paseo or OpenAI product.
